## Why the previous session "ended without an idle timeout"

Not a crash, not an idle reaper, and not a runtime restart. The conversation
stopped with an explicit `ConversationErrorEvent`:

```
Agent reached maximum iterations limit (500).
```

`meta.json` sets `max_iterations: 500`, and event `05482` is that error after
`05481` state updates. The agent was working normally right up to the cap; the
container was only restarted *later* (uptime was 6 min when this session began),
which is what made it *look* like an unexplained stop. There is no
"idle timeout" in the event stream at all.

Diagnostic recipe for next time: scan `events/*.json` for non-`agent` sources
and any `*ErrorEvent`; the reason is always an event, never inferred.

## Fixed: the source-install snippet was a rename trap

`Install.astro` cloned from `${REPO}` (from `REPO_SLUG`) but ran a hard-coded
`cd LinguaFix`. Identical strings today, so it works — and breaks the instant
the repo is renamed, for everyone who copy-pastes the snippet. `consts.ts` now
exports `REPO_NAME`; the snippet derives the directory from it. New guards in
`tests/test_repo_urls.py` pin the Astro snippet to `${REPO_NAME}` and the
`git clone`/`cd` pairs in `README.md` + `docs/*` to the live repo name.
