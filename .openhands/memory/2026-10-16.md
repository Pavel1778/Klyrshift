# 2026-10-16

## 2026-10-16 - Rename defect: OG image still said "LinguaFix"

- `site/public/og-image.png` (1200x630 social preview, referenced by
  `site/src/layouts/Base.astro` as `og:image`/`twitter:image`) was hand-made
  before the rename, so the binary kept rendering **LinguaFix**. A text-only
  rename never touches a bitmap - found it by OCR'ing the PNG with `tesseract`.
- Fixed with a reproducible generator: `scripts/make_og_image.py` inlines
  `site/public/logo.svg` + the self-hosted Inter/JetBrains Mono woff2 that Astro
  emits (`site/dist/_astro/fonts/`), renders absolute-positioned HTML with
  headless `chromium`, and refuses to write if the old name is present.
- It needs a prior `npm run build` in `site/` (fonts are gitignored); raises
  `SiteNotBuilt` otherwise, which the test turns into a skip.
- `tests/test_og_image.py` pins size, a non-blank render, the served path, and
  (via `tesseract`, skipped when absent) that the card shows `Lingvix`.
- Measured every element's bbox against the original and matched them
  (logo blue square 90,120,240,270; title cap 279,140..209; subtitle width
  867 vs 865; card blue arrow 407..446; footer 566..598). Environment note: no
  PIL/cairo/gi here - decode/encode PNG with pure Python (`struct`+`zlib`).
