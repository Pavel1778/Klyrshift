# Имена и фамилии

Личные имена и распространённые фамилии, чтобы имя не «исправлялось».

| Файл | Язык | Объём |
|---|---|---|
| `ru-names-1k.txt` | русский | 194 слов |
| `en-names-1k.txt` | английский | 246 слов |

## Источник и лицензия

Составлено вручную (manual curation) для проекта Klyrshift, лицензия — MIT
(см. корневой `LICENSE`). Слова — общеупотребительные имена и термины; они не
являются объектами авторского права как отдельные слова.

## Установка

```bash
klyrshift dict install names --lang ru
```
