|---|---|---|

## Источник и лицензия

Составлено вручную (manual curation) для проекта Klyrshift, лицензия — MIT
(см. корневой `LICENSE`). Слова — общеупотребительные имена и термины; они не
являются объектами авторского права как отдельные слова.

## Установка

```bash
klyrshift dict install code --lang ru
```
